# Support

Use [Q&A](https://github.com/luantaraschi/anti-slop/discussions/categories/q-a) for installation help, audit interpretation, and questions about a tell. Include the plugin version, the invocation you used, and the smallest relevant code sample.

Use an issue when you can reproduce a defect. Security problems belong in the private vulnerability form described in `SECURITY.md`.

This project does not provide private installation or design support.
